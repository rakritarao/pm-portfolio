# Rakrita Rao — Product Management Portfolio

A product-focused portfolio built with plain HTML, CSS, and JavaScript and designed for GitHub Pages.

## Local preview
Open `index.html` in a browser, or run a simple local server from the repository directory.

## GitHub Pages
1. Create a new GitHub repository (suggested name: `pm-portfolio`).
2. Push the contents of this folder to `main`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Structure
- `index.html` — homepage
- `css/styles.css` — responsive design
- `js/main.js` — scroll reveal and footer year
- `case-studies/` — individual product case studies
- `assets/resume/` — PM resume
- `assets/images/` — future screenshots and product artifacts
